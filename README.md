# Spotify Music Analytics Dashboard

## Project Overview

This project analyzes Spotify music data using Excel, PostgreSQL, Python, and Power BI. The objective is to clean the data, perform SQL analysis, conduct exploratory data analysis (EDA), and build an interactive dashboard for business insights.

---

## Business Objective

- Analyze Spotify music trends
- Identify top-performing artists and genres
- Understand song popularity
- Explore streaming patterns
- Build an interactive business dashboard
